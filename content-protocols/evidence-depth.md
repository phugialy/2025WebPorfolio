# Evidence Depth Protocol

The evidence layer prevents thin articles from being stretched into confident or oversized content.

## Evidence Levels

- Light: 1-2 usable sources. Suitable for idea-led notes or short commentary.
- Standard: 3-5 credible sources. Suitable for normal articles.
- Strong: 5-8 credible sources. Suitable for deep articles.
- Deep: 8-12 sources with primary or official sources. Suitable for practical research papers.

## Required Source Minimums

- Article: 2 credible sources minimum, 3-5 preferred.
- Deep article: 5 credible sources minimum.
- Paper: 8 credible sources minimum.
- Current/trending topic: at least 2 recent sources required.

## Source Usefulness

A source counts more when it contributes one of:

- factual claim
- statistic or raw data point
- expert position
- product/release detail
- case/example
- contradiction
- risk/limitation
- practical implication

## Proceed/Hold Rules

- If evidence depth is too low, write shorter and mark evidence gaps.
- Do not stretch weak research into a long paper.
- If current facts need retrieval and no fresh sources exist, mark retrieval incomplete.
- If source count is low, the writer should frame the draft as idea-led.
